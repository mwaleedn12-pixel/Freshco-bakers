# Modules 14–16 — Customer Web Portal, Admin Dashboard & POS Counter Billing

Pushed / Built status: 📦 Complete & Ready for Presentation

## 1. Features Delivered for Web Technologies University Presentation
- **Customer Web Portal**:
  - Interactive 3D tilt card animations for featured breads & cakes (`styles.css` & `app.js` 3D perspective matrix engine).
  - Live catalog search & category filtering.
  - Custom Cake quotation builder with flavour, size, event theme, and custom message options.
  - Real-time order tracking timeline.
  - Customer review submission & 5-star rating system.
- **Executive Admin Dashboard**:
  - KPI summary cards (Revenue, Fulfilled Orders, Pending Kitchen Orders, Low Stock Alerts).
  - Products catalog CRUD table & inventory alert monitors.
  - Kitchen Orders Kanban Board (Pending, Preparing, Ready, Out for Delivery, Delivered).
  - Staff management & store settings configuration.
- **Phase 2 POS Counter Billing**:
  - Barcode scanner simulation & SKU lookup.
  - Instant counter cart calculation with cash/card/wallet payment options.
  - Printable 58mm / 80mm thermal receipt generator modal.
  - Daily cash closing reconciliation report.
- **Presentation Role Switcher**:
  - One-click header switcher (`Customer Portal`, `Admin Dashboard`, `POS Counter Billing`) enabling effortless demonstration in university class.
